# Pacotes de conteúdo

Pacotes de metodologia instaláveis pela Ferramenta FPSI.

| Id | Tipo | Origem |
|----|------|--------|
| `ppsi-2.0` | conteúdo | terceiro (SGD/MGI) |
| `governanca-ia` | conteúdo | próprio FPSI |
| `framework` | conteúdo | próprio FPSI (encaixe vazio) |

O site institucional vive em [`packages/publico`](../packages/publico).

Instalação: `npm run install:fpsi` (padrão = todos). Flags de exclusão: `-public`, `-ia`, `-framework`, `-ppsi`.
